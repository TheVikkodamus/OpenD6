## Core Mechanic

Roll a number of six-sided dice equal to your attribute or skill die code. Add the results. If your total **equals or exceeds** the difficulty number, you succeed.

**Die Codes** are written as `#D` (number of dice) plus optional pips: `3D+1` = roll 3 dice, add 1.  
Each die = 3 pips: `1D = 1D+0`, `1D+1`, `1D+2`, `2D = 1D+3`.

### The Wild Die

One die in every roll must be a different color — this is the **Wild Die**.

| Wild Die Result | Effect |
|-----------------|--------|
| **6** | Critical Success — add 6, roll Wild Die again; keep adding & rolling as long as 6s appear |
| **2–5** | Normal — add to total as usual |
| **1** (first roll only) | Critical Failure — remove the 1 **and** your highest die; add the rest |

### Special Points

| Point | How to Spend | Effect |
|-------|-------------|--------|
| **Character Point** | After rolling (or before) | Roll one extra Wild Die; add best result |
| **Fate Point** | Before rolling | Double your dice for one action this round |

Characters start with **5 Character Points** and **1 Fate Point**. Points are earned by completing adventures and roleplaying well. Spent Fate Points may be recovered if used in a heroic or climactic moment.

## Character Creation

### Method 1 — Template
Pick a template from the rulebook. Distribute **7 skill dice** among its listed skills (max +3D to any one skill). Equipment is already provided.

### Method 2 — Defined Limits
Distribute **18 attribute dice** (min 1D, max 5D per attribute; Extranormal starts at 0D).  
Then distribute **7 skill dice** (max +3D to any one skill).

### Method 3 — Creation Point Pool
Start with **79 creation points**.

| Purchase | Cost |
|----------|------|
| 1 attribute die | 4 CP |
| 1 skill die | 1 CP |
| 3 skill specialization dice | 1 CP |
| Advantages / Special Abilities | see listings |

Humans may take up to **10 CP worth of Disadvantages** to gain bonus points.

### Starting Values (All Methods)

| Characteristic | Starting Value |
|----------------|----------------|
| Move | 10 meters/round |
| Body Points | Roll Physique + 20 |
| Strength Damage | Physique or lifting ÷ 2 (drop pips, round up) |
| Funds | 3D base (see Funds modifiers) |
| Character Points | 5 |
| Fate Points | 1 |

### Funds Modifiers

| Condition | Modifier |
|-----------|----------|
| 1D in Charisma | −1 |
| 1D in Intellect | −1 |
| 4D+ in Charisma | +1 |
| 4D+ in Intellect | +1 |
| 8D+ in trading + highest specialization | +1 |

Multiply Funds total × ~60 silver for weekly income equivalent.

### Experienced Characters

Add per year of full-time adventuring (halve for part-timers):

| Method | Per Year |
|--------|---------|
| Template / Defined Limits | +15 skill dice, +15 CP, +2 Fate Points |
| Creation Point Pool | +15 CP, +15 CP (for skills), +2 Fate Points |

## Attributes

| Attribute | Covers |
|-----------|--------|
| **Agility** | Balance, quickness, full-body motor skills |
| **Coordination** | Hand-eye coordination, fine motor control |

## Improving Characters

Improvement happens **between adventures** using Character Points.

### Skill Improvement

| Action | Cost (CP) |
|--------|----------|
| Learn a new base skill (1 pip) | = number before "D" in governing attribute |
| Improve an existing skill (1 pip) | = number before "D" in current skill die code |
| Learn a new specialization (1 pip) | = ½ of number before "D" in attribute or skill (round up) |
| Improve an existing specialization (1 pip) | = ½ of number before "D" in specialization die code (round up) |

**Example:** Raising dodge from 4D+2 to 5D costs 4 CP. Raising it again to 5D+1 costs 5 CP.

Magic skills cost **double** the normal amount. Without a teacher, double again (×4 total).

### Attribute Improvement

Attributes can also be improved using Character Points, at 10× the number before the "D" per pip.

### Obtaining Magic After Play

Initial purchase of 1D Magic: **20 CP**. After that: 10× the die number per pip.

## Game Basics — Rolls & Difficulties

### Standard Difficulty Levels

| Level | Number | Example |
|-------|--------|---------|
| Automatic | 0 | Walking on flat ground |
| Very Easy | 1–5 | Lifting a light object |
| Easy | 6–10 | Climbing a tree with knots |
| Moderate | 11–15 | Picking a simple lock |
| Difficult | 16–20 | Tracking in rain |
| Very Difficult | 21–25 | Forging official documents under pressure |
| Heroic | 26–30 | Near-impossible feats |
| Legendary | 31+ | The stuff of legend |

### Generic Difficulty Modifiers

| Modifier | Situation |
|----------|-----------|
| +16 or more | Overwhelming disadvantage (repairing without tools) |
| +11–15 | Decisive disadvantage (finding someone in complete darkness) |
| +6–10 | Significant disadvantage (tracking through drizzle) |
| +1–5 | Slight disadvantage (picking a lock by candlelight) |
| −1–5 | Slight advantage (springy surface for jumping) |
| −6–10 | Significant advantage (knotted rope for climbing) |
| −11–15 | Decisive advantage (well-stocked healer's kit) |
| −16 or more | Overwhelming advantage (purpose-built tools) |

### Result Points

The difference between your roll and the difficulty. The GM can use these to judge quality:

| Result Points | Success Level |
|---------------|---------------|
| 0 | Minimal — barely succeeded |
| 1–4 | Solid — task completed cleanly |
| 5–8 | Good — better than needed; possible added benefits |
| 9–12 | Superior — significantly above expectations |
| 13–16 | Spectacular — onlookers take notice |
| 17+ | Incredible — memorable achievement |

Half the result points (rounded up) may be used as a bonus to a related follow-up roll.

### Opposed Rolls

Both characters roll their relevant skill. Higher total wins; ties go to the initiator.

### Initiative

Roll Acumen; higher total acts first.

### Multi-Action Penalty

Taking more than one action in a round: −1D to all rolls for each action beyond the first.

### Untrained Skill Use

Using a skill without any training: +1 to +5 or more added to the difficulty, at the GM's discretion.

## Combat

### Combat Sequence Each Round
1. Determine initiative (Acumen roll)
2. Attack and defend
3. Determine damage
4. Repeat if needed

### Attack Difficulties

**Base combat difficulty:** 10 (target's passive defense value)

The target may use an **active defense** on their turn: roll dodge, fighting (block/parry), or melee combat. That total replaces the passive defense value for all attacks after the defender's turn until their next turn.

**Full defense:** Forfeit all actions; roll active defense skill + 10. Applies to all attacks until next turn.

### Range Modifiers

| Range Category | Modifier to Combat Difficulty |
|----------------|------------------------------|
| Point Blank (0–2m) | −5 |
| Short | 0 (base) |
| Medium | +5 |
| Long | +10 |

### Scale

When opponents of very different sizes fight, find each combatant's scale value and calculate the modifier:

- Both larger-or-equal to Human, or both smaller: subtract smaller from larger
- One larger, one smaller than Human: add both values

If attacker is **larger**: add modifier to combat difficulty and to damage total.  
If attacker is **smaller**: add modifier to attacker's combat skill and to defender's damage resistance.

| Scale Value | Example |
|-------------|---------|
| 0 | Average Human |
| 3 | Horse, large carriage, Human child |
| 6 | Small building, elephant |
| 8 | Large elephant |
| 10 | One-story building |
| 12 | Longship |
| 14 | Two-story building |
| 21 | War galley |
| 24 | Eight-story castle |

### Determining Damage

**Melee / Thrown / Muscle-powered missile weapons:**  
`Weapon Damage + Strength Damage` vs. target's damage resistance total

**Other weapons:** Weapon Damage vs. damage resistance total

**Damage resistance total:** Physique roll + Armor Value + other modifiers

If `damage total > resistance total`: subtract difference from Body Points (or determine Wound level).

### Strength Damage

Drop pips from Physique or lifting → divide by 2 → round up.

| Physique/Lifting | Strength Damage |
|-----------------|-----------------|
| 1D | 1D |
| 2D | 1D |
| 3D | 2D |
| 4D | 2D |
| 5D | 3D |
| 6D+2 | 3D |

### Common Combat Options

| Option | Effect |
|--------|--------|
| **Called Shot** | +1D to +8D to difficulty; on success: knock item away, pin limb, or +1D damage |
| **Knockout** | Half damage, but must be called shot to head; ≥2 Wound levels renders unconscious |
| **Disarm** | Opposed Physique/lifting; target may resist if they haven't acted yet |
| **Hold** | −3D or more damage but you grab the target |
| **Slam/Throw** | Lift (lifting roll) then throw (throwing roll); target takes obstacle's damage + your Str Damage |
| **Entangle** | Marksmanship or throwing; target trapped; must break free with Physique or slip free with Agility |
| **Group Attack** | Coordinate with command skill; all gain +1D to attack per additional attacker (max +4D) |
| **Quick Draw** | Announce before initiative; shift skill dice to Acumen; act earlier in round |
| **Surprise** | Act first OR gain +1D to action |

| Location | Difficulty Modifier | Damage Modifier | Effect on Injury |
|----------|-------------------|-----------------|-----------------|
| Head | +1D (+5) | +12 | −1 to Intellect/Acumen/initiative totals |
| Heart | +4D (+15) | +12 | Potentially fatal |
| Chest / abdomen | 0 | 0 | No other actions next round |
| Arm | +1D (+5) | −2 | −1 to arm-related actions |
| Leg | +1D (+5) | −1 | −1 to movement-related actions |

## Damage & Healing

### Body Points System

Subtract damage from Body Points. At 0 BP: incapacitated or dead.

**Wound Levels** (used alongside or instead of BP):

| Wound Level | BP Range (typical) | Penalty |
|-------------|-------------------|---------|
| Stunned | 20–27 | −1D to all actions until healed |
| Wounded | 14–19 | −2D to all actions |
| Severely Wounded | 7–13 | −3D to all actions |
| Incapacitated | 4–6 | May not act; needs help |
| Mortally Wounded | 1–3 | Dying; needs immediate care |
| Dead | 0 | — |

### Healing

**Body Points:** Recover through rest, medical care (healing skill), or magic.

**Wound Levels:** A successful healing roll can remove one Wound level. Difficulty depends on severity. Natural rest removes one level per day with a successful stamina roll (difficulty = 5 × current Wound level).

## Magic

Magic is an Extranormal attribute available only to those with dice in it. All spells use one of the four Magic skills. Roll the skill against the spell's difficulty.

### Obtaining Magic

- At character creation: spend attribute dice on Magic
- After play: 20 CP for 1D in Magic; then 10× die number per pip
- Magic skills cost 2× normal CP to improve; without a teacher, cost 4× normal

### Magic Skills Summary

| Skill | Governs |
|-------|---------|
| **Alteration** | Changing or modifying existing things |
| **Apportation** | Moving things; teleportation |
| **Conjuration** | Creating things from nothing; animating the inanimate |
| **Divination** | Obtaining knowledge; scrying |

### Spell Characteristics

Every spell has these aspects:

| Aspect | Description |
|--------|-------------|
| Skill Used | Which Magic skill to roll |
| Difficulty | Number to meet or beat |
| Effect | What the spell does and its value |
| Range | Maximum distance from caster (in meters) |
| Speed | How fast the spell travels |
| Duration | How long the effect lasts |
| Casting Time | How long the caster must spend preparing |
| Other Aspects | Components, gestures, conditions, etc. |

### Using Spells

1. Roll the listed Magic skill against the spell's difficulty.
2. If the spell requires targeting (e.g., a fireball), also make a targeting roll (usually marksmanship) against normal combat difficulty.
3. Apply the effect. Result points may be applied to **one** aspect: effect, range, or duration (add half the result points, rounded up, to the chosen aspect's value).

Casting a spell + using its targeting skill is **not** considered multi-action. Adding a weapon attack in the same round **is**.

### Designing Spells

Spells are built from a **Spell Total** (aspects that expand the effect, making it more powerful) minus a **Negative Spell Total Modifier** (aspects that add restrictions, making it harder to use).

**Final Difficulty = (Spell Total − Negative Modifier) ÷ 2 (round up)**

**Key Aspects & Their Values:**

| Aspect | Value | Notes |
|--------|-------|-------|
| Effect (die code) | Use Die Code table | 3D = 9; 6D = 18; 10D = 30 |
| Effect (Special Ability) | 3 × SA cost × ranks | Plus enhancements, minus limitations |
| Range | Use Spell Measures table | In meters |
| Speed | Use Spell Measures table | In meters/second |
| Duration | Use Spell Measures table | In seconds |
| Area Effect | Use Spell Measures table | Radius in meters |
| Charges | +2 per charge | Stored uses |
| Multiple Targets | +3 per additional target | Beyond first |
| Variable Effect | +5 | Caster can increase effect value up to 5 at casting |
| Focused | +5 | Locks effect onto a specific target |

**Negative Modifiers (reduce difficulty):**

| Modifier | Value | Notes |
|----------|-------|-------|
| Casting Time | −1 to −18+ | Longer time = bigger reduction |
| Gesture | −1 to −3 | Simple to complex action required |
| Incantation | −1 to −3 | One word to paragraph required |
| Components | −1 to −12 | Common to very rare items consumed or required |
| Concentration | −1 to −5 | Must succeed at a mettle check during casting |
| Conditions | −1 to −6 | Spell only works under specific circumstances |
| Feedback | −3 | Caster takes damage equal to failed margin |
| Unreal Effect | −1 to −9 | Target can disbelieve; effect ends if they succeed |
| Community | −2 to −6 | Requires additional casters |

### Scrivened Spells (Scrolls)

Any spell without charges, wards, or unique components may be inscribed on paper. Anyone who reads it can trigger it once — even non-magic users. The scribe cannot use their own scrolls. Add these aspects to the base spell:

- Charge: +2 (triggered when read)
- Components: paper and ink (−6)
- Concentration: 4 min (−3)
- Gesture: write description of spell (−2)

Adjust difficulty down based on the scroll formula (see rulebook p. 99 for full calculation).

## Miracles

Miracles are divine invocations granted through faith. Mechanically similar to Magic but with different rules and restrictions.

### Key Differences from Magic

| Aspect | Magic | Miracles |
|--------|-------|---------|
| Source | Arcane skill | Divine patron |
| Skills | alteration, apportation, conjuration, divination | divination, favor, strife |
| Designing | Spell design system (full) | Same system, with restrictions |
| Cost to learn | 2× normal CP | 2× normal CP |
| Countermagic works on | Yes | Yes (via Disrupt Spell miracle) |

**Disallowed Miracle aspects:** Generally no Unreal Effect, limited use of Feedback and Countenance.

### Miracle Skills

| Skill | Governs |
|-------|---------|
| **divination** | Gaining knowledge of past, present, or future |
| **favor** | Healing, blessing, enhancing, and benefiting |
| **strife** | Causing harm, banishing, cursing, raising undead |

### Miracle Success Bonus

Like result points in spells, a miracle's success margin adds to effect totals. The invoker must choose which aspect (effect, range, or duration) before invoking.
